# 04 · 冻结模块清单（51 个）

## 定制模块（核心逆向对象）

| 模块 | 说明 |
|---|---|
| `xiaozhi.py` | 小智主逻辑（协议/状态机，重点还原目标） |
| `client.py` | 客户端封装 |
| `ovoui.py` | 屏幕 UI（表情渲染等） |
| `ovomini.py` | 板卡专用模块（含中文颜色名，qstr 池含 UTF-8） |
| `user.py` | 用户配置/挂载点 |
| `onboarding.py` | 配网引导 |
| `wifinet.py` | WiFi 管理 |
| `boot.py` / `_boot.py` | 启动脚本 |
| `flashbdev.py` / `inisetup.py` | 文件系统 |
| `machine.py` / `pinutil.py` | 板级封装 |

## 标准库 / 第三方（官方 mir/esp32 ports 常见冻结）

- asyncio 族：`asyncio_*.py`、`uasyncio.py`（8 个）
- 传感器/外设驱动：`DS1302` `bmp280` `hcsr04` `hx711` `i2c_lcd` `lcd_api` `mpu6050` `neopixel` `pn532` `sdcard` `ssd1306` `tm1637`
- 红外：`ir_rx_*`（6 个）
- 网络/通信：`espnow` `ntptime` `requests` `simple` `ssl` `umqtt_robust` `umqtt_simple` `webrepl_cfg` `wifinet`
- 工具：`upysh` `hid_services` `mip`

## 原生 C 模块（无法从冻结区提取）

`usermods/xiaozhi_native/modxiaozhi.c` —— 编译进 IROM 段的原生模块
（音频/协议底层），逆向需走 disasm/*.dis 的机器码分析路线。

## 文件对应关系

- `extracted/<name>.mpy` —— 按逆向格式重建，可被 `tools/mpy_tool.py -d` 解析
- `disasm/<name>.dis` —— 对应反汇编文本
- 注意：旧命名残留（双下划线 `__`）文件为 v1 废品，已清理；当前清单为 v2 精确版本
