# 02 · 固件身份与 flash 布局

## 固件指纹

| 项目 | 值 |
|---|---|
| 文件 | firmware_esp32s3_N16R8_xiaozhi.bin（2,978,018 字节 ≈ 2.84MB） |
| MicroPython | 1.30.0-preview |
| fork commit | 8cb7558d00-dirty（私有 fork，未公开源码） |
| ESP-IDF | v5.5.3 |
| 构建日期 | 2026-10-25（固件内嵌字符串） |
| 芯片 | ESP32-S3 N16R8（16MB flash / 8MB PSRAM） |

## flash 布局

| 偏移 | 内容 |
|---|---|
| 0x0 | 小引导 app（bootloader） |
| 0x10000 | 主固件（7 个段） |
| 0x290000 | ESP-SR 离线唤醒词 `wn9_nihaoxiaozhi_tts` |

> 整包 bin 从 0x0 一次性烧入即可，无需分段。

## 段映射表（segs.json，load_addr / len / file_offset）

| # | load 地址 | 长度 | 文件偏移 | 段类型 |
|---|---|---|---|---|
| 0 | 0x3C1D0020 | 0x6DCB0 | 0x10020 | DROM（含冻结模块元数据） |
| 1 | 0x3FC9F500 | 0x2340 | 0x7DCD8 | D/IRAM 数据 |
| 2 | 0x42000020 | 0x1C4418 | 0x80020 | IROM（代码） |
| 3 | 0x3FCA1840 | 0x4EE0 | 0x244440 | 数据 |
| 4 | 0x40374000 | 0x1B3FC | 0x249328 | IRAM |
| 5 | 0x50001000 | 0x20 | 0x26472C | RTC |
| 6 | 0x600FE000 | 0x38 | 0x264754 | 外设寄存器初始化 |

冻结模块元数据（mp_frozen_names / mp_frozen_content）位于 0x49B70 附近（DROM 段内）。

## 提取方法

`tools/extract_mpy2.py` 依据上表做虚拟地址→文件偏移换算（`v2f()`），
定位 `mp_frozen_module_t` 结构，按 fork 的编码规则重建出可被
`mpy_tool.py -d` 正常反汇编的 .mpy 文件。产物见 `extracted/`。
